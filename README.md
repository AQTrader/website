# 天衍智投 - TianYan AI Trading Platform

> AI驱动的下一代量化交易平台

天衍智投是一个基于人工智能和大语言模型的智能量化交易分析平台。融合先进的深度学习算法与实时市场数据,为投资者提供专业的交易策略与智能决策支持。

## 🌟 特色功能

- **LLM 智能分析引擎** - 基于大语言模型的多维度市场分析系统
- **实时行情图表** - 集成TradingView高级图表库,提供专业级K线图与技术指标
- **量化策略回测** - 强大的策略回测引擎,支持多品种、多周期历史数据回测
- **智能信号推送** - AI模型自动识别交易机会并推送实时信号
- **全方位风控系统** - 多层次风险控制体系

## 🛠️ 技术栈

- **前端**: Vue.js 3, TradingView Advanced Charts, D3.js, WebSocket
- **后端**: Node.js, Python FastAPI
- **AI引擎**: LLM大语言模型, PyTorch, 强化学习, NLP文本分析
- **基础设施**: Redis, Kafka
