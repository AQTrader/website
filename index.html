关于 天衍智投

「天衍」取自《易经》天衍之数，象征万物演化之规律。
我们致力于用人工智能解码市场的深层逻辑，将古老的哲学智慧与前沿科技完美融合。

愿景

构建全球领先的AI量化交易生态系统，让每一位投资者都能享受到人工智能带来的精准分析与智能决策。

使命

通过大语言模型、深度强化学习与实时数据分析技术，消除信息不对称，赋能投资者做出更明智的交易决策。

价值观

技术驱动、数据为本、风险至上。我们相信科学的方法论是在复杂市场中获得持续优势的唯一途径。

TradingView Advanced Charts 集成

我们深度集成TradingView高级图表库（Advanced Charts Library），为用户提供机构级别的交互式图表体验。通过自定义数据源适配器（Datafeed API）， 我们将AI模型的预测结果、自定义技术指标及交易信号直接叠加在专业K线图上，实现分析与可视化的无缝融合。

  • 通过 Datafeed API 接入自有数据源，支持股票、期货、加密货币等多品种实时行情
  • 自定义技术指标开发，将AI模型输出以指标形态展示在图表中
  • 交易信号标注系统：在K线图上实时标记AI生成的买卖信号
  • 多图表联动布局，支持多品种、多周期的同屏对比分析
  • 深色主题定制，与平台整体暗色调设计风格统一协调

AI 模型与策略引擎

利用大语言模型（LLM）进行多源信息融合分析，结合深度强化学习（DRL）训练交易策略。 模型涵盖时序预测（Transformer）、情绪分析（BERT/FinBERT）、异常检测等多个维度， 构建立体化的市场认知框架。

  • 基于 Transformer 架构的多维度时序预测模型
  • FinBERT 金融文本情绪分析引擎
  • PPO/SAC 深度强化学习策略优化
  • 异常检测与市场状态识别系统
  • 模型性能监控与自动再训练管线
